# Правила формата имени страницы

Имя создаваемой страницы требований должно иметь формат:

```text
{{req.id}} - {{req_template.subject}}
```

где `{{req.id}}` — идентификатор запроса, в рамках которого создается страница в Confluence (выясняется у пользователя в начале работы скилла или суб-агента), `{{req_template.subject}}` — заголовок шаблона.
Пример - https://itpm-wiki.mos.ru/pages/viewpage.action?pageId=738465450
