# Манифест проекта mos_itsm_confl_page_creator

## Назначение

Публикация набора файлов `*.md` как страниц корпоративного Confluence
(https://itpm-wiki.mos.ru, пространство 4ME). Markdown — источник истины.

## Структура

| Папка | Содержимое |
|---|---|
| `pages/` | Ваши файлы `*.md` — то, что публикуется |
| `script/` | Скрипты публикации и Python-окружение `venv` |
| `output/` | Журналы публикаций (`publish-<дата>.log`) |
| `temp/` | Одноразовые рабочие копии для локальной проверки |
| `references/` | Настройки сервера (`server-setup.md`) |

## Скрипты

- `script/local-check.sh [каталог]` — локальная проверка конвертации, сервер не затрагивается.
- `script/find-page.sh "название"` — найти номер страницы по названию (для выбора родителя).
- `script/find-page.sh --spaces` — список пространств.
- `script/publish.sh <каталог-или-файл> [--root-page ID]` — публикация.

## Порядок публикации

1. Положить `*.md` в `pages/`.
2. `local-check.sh` — проверить конвертацию локально.
3. Согласовать родительскую страницу (спрашиваем перед каждой публикацией).
4. `publish.sh <каталог> --root-page <ID>` — публикация после явного согласия.
5. Проверка результата в браузере.

## Установка окружения (один раз)

```bash
cd script
python -m venv venv
venv/Scripts/python -m pip install "markdown-to-confluence==0.6.1"
```

## Токен

Хранится в файле `.env` в корне проекта (`D:\_DIT\_dit_git_repos\mos_itsm_confl_page_creator\.env`):

```
CONFLUENCE_API_KEY="ваш-токен"
```

Скрипты читают его автоматически. Значение токена агенту не раскрывается —
проверяется только факт, что переменная задана. Без неё скрипты работу прерывают.
