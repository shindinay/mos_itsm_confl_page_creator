# Маппинг переменных для вложенных шаблонов Confluence

Версия: 1.0 (29.10.2026).

Вложенные шаблоны (подставляемые по `**confluence_template_id_{{id}}**`) содержат
собственные переменные-плейсхолдеры вида `**имя_переменной**`. Эти переменные
должны быть заполнены данными из скиллов МосИТСМ.

## Шаблон 736854040 — "Расширение UI"

**Шаблон:** https://itpm-wiki.mos.ru/pages/templates2/viewpagetemplate.action?entityId=736854040&key=DIT4ME  
**Назначение:** Вставка описания расширения UI задачи/шаблона в страницу требований.

| Переменная | Описание | Источник |
|---|---|---|
| `**ui_extension_uri**` | Ссылка на расширение UI в МосИТСМ (QA) | `ui_extension.uri` из данных скилла `mos_itsm_get_obj_structure` (режим `uiext`) |
| `**ui_extension_description**` | Назначение расширения UI | Поле `description` или `title` расширения UI |
| `**req_uri**` | Ссылка на запрос (РП/ЗНИ) | `request.uri` из переменных запроса |
| `**description_from_md-file**` | Полное описание расширения UI | Берётся из файла `desc_<id>.md`, сгенерированного скиллом `mos_itsm_ui_extension_descriptor` |

## Шаблон 736854041 — "Правило автоматизации"

**Шаблон:** https://itpm-wiki.mos.ru/pages/templates2/viewpagetemplate.action?entityId=736854041&key=DIT4ME  
**Назначение:** Вставка описания правила автоматизации задачи/шаблона в страницу требований.

| Переменная | Описание | Источник |
|---|---|---|
| `**ar_link**` | Ссылка на правило автоматизации в МосИТСМ (QA) | `<a href="https://itsm.itsm-qa.mos.ru/automation_rules/{id}">Правило автоматизации {id}</a>` |
| `**ar_description**` | Краткое описание правила автоматизации | Поле `description` правила; если пусто — генерируется из `trigger` + `condition` |
| `**trigger**` | Триггер правила автоматизации | Поле `trigger` правила |
| `**condition**` | Условие правила автоматизации | Поле `condition` правила |
| `**related_obj_link**` | Объект автоматизации (ссылка на request_template) | Ссылка на `request_template`, в котором определена задача, содержащая правило. Формат: `<a href="https://itsm.itsm-qa.mos.ru/request_templates/{template_id}">... | Шаблон запроса</a>` |
| `**description_from_md-file**` | Полное описание правила | Берётся из файла `desc_<id>.md`, сгенерированного скиллом `mos_itsm_automation_rule_descriptor`, или из поля `description_html` правила |

## Правила маппинга

1. **Приоритет:** сначала проверяем, что скилл-построитель страницы уже сгенерировал для переменной конкретное значение (файл `desc_<id>.md` или заполненную таблицу данных).
2. **Если значение из источника доступно** — подставляем его в переменную шаблона.
3. **Если значение недоступно** — оставляем плейсхолдер `**имя_переменной**` как есть и перечисляем незаполненные места в итоговом отчёте.
4. **Вложенные плейсхолдеры:** если внутри подставленного шаблона остались `**confluence_template_id_...**` — обрабатываем рекурсивно.
5. **`ar_description` и `related_obj_link`** — обязательны для каждого правила автоматизации. Если правило не привязано к task_template, `related_obj_link` может быть пустым.
