# Настройки сервера Confluence (проверено 2026-10-25)

| Параметр | Значение |
|---|---|
| Адрес | https://itpm-wiki.mos.ru/ |
| Схема | только https (http сам редиректит на https) |
| Тип | корпоративный сервер (Data Center/Server), базовый путь `/` (без `/wiki`) |
| REST API | `https://itpm-wiki.mos.ru/rest/api/...` (v1) |
| Пространство публикации | `4ME` |
| Аутентификация | Bearer-токен (PAT), переменная `CONFLUENCE_API_KEY` из файла `.env` в корне проекта |
| Инструмент | `markdown-to-confluence==0.6.1` (CLI `md2conf`) в `script/venv` |
| Навык-инструкция | `~\.zcode\workspace\default\.claude\skills\md2conf\SKILL.md` |

## Флаги публикации (publish.sh)

- `--api-version v1` — обязательно для Data Center (v2 только для облачного Atlassian).
- `--path /` — базовый путь корпоративного сервера (не `/wiki/`).
- `--no-overwrite` — не затирать страницы с ручными правками после последней синхронизации.
- `--webui-links` — рекомендуется для локальных (on-premise) серверов Confluence.
- `--no-notify` — обновления как «мелкие правки», без массовых уведомлений.

## Ограничения

- Проверка сертификата отключаемой опции не имеет; если сервер использует внутренний
  удостоверяющий центр, доверие настраивается на уровне Python-окружения (заметка
  будет дополнена при первом реальном запуске).
- Токен PAT создаётся в Confluence: профиль → Настройки → Личные токены доступа.
